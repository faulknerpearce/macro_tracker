Macro Tracker · design system

Calm version · design system

Same data, less noise. Blue is only for data, amber only for controls (as a fill, with dark text), rust only for going over a limit. Charts carry the numbers with labeled axes and legends; text is kept to short stats.

7 · Rules

Blue = data. Never on text, headers or buttons. Data blue text fails small-text contrast, so values stay in the text color.

Amber = control. Only as a fill with dark text: buttons, selected day, +. Never amber text.

Rust = over a limit. Plus the "new" dot. Always with an icon and words.

Fewer words. Stats instead of sentences; no sub-captions under charts or lists; legends with samples instead of "dashed line means…".

Charts are readable. Labeled axes, data clear of the axis, nothing overlapping text, target ranges with visible edges and labels.

One card pattern. Header in the card, lines between rows. Icons match the log type.

Accessibility. AA text contrast, 44 px targets, chart descriptions for screen readers, status never by color alone.

Two typefaces. Outfit for big numbers and titles, Inter for everything else; small uppercase section labels.
